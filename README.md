# Приложение для отслеживания поз человека и анализа упражнений с использованием YOLOv11 и LSTM

Приложение для отслеживания поз человека в реальном времени с использованием YOLOv11 Pose Detection. Поддерживает запись видео с камеры и обработку готовых видео файлов.
Также включает серверное API для дистанционной обработки видеофайлов.

## 🌟 Возможности

*   **Реальная запись с камеры** - Запись видео с веб-камеры с наложением ключевых точек позы (в десктопной версии).
*   **Обработка готовых видео** - Анализ существующих видео файлов с применением модели LSTM для анализа качества выполнения упражнений (в десктопной версии и через API).
*   **Автоматическая конфигурация** - Интеллектуальный выбор параметров на основе характеристик системы (в десктопной версии).
*   **Cохранение файлов** - Все результаты сохраняются в отдельную папку на рабочем столе (в десктопной версии): `../username/desctop/Записи работы модели`
*   **Поддержка разных моделей** - Small и Large для разных задач (в десктопной версии).
*   **Серверное API** - Возможность дистанционной отправки видеофайлов на обработку и получения результата через HTTPS.

## 📋 Требования:

*   Python 3.7+ (3.12.3 - оптимально)
*   CUDA (опционально, для GPU ускорения)
*   Веб-камера (для записи в реальном времени в десктопной версии)

## 📦 Основные файлы

*   `main.py`: Исходный код десктопного приложения с GUI.
*   `server_api.py`: Код серверного API для обработки видео по запросу.

## 🚀 Запуск серверного API

1.  Убедитесь, что все зависимости установлены: `flask`, `opencv-python`, `ultralytics`, `tensorflow`, `numpy`, `Pillow`.
2.  Убедитесь, что файлы `squat_model.h5`, `features_mean.npy`, `features_std.npy` находятся в той же папке, что и `server_api.py`.
3.  Запустите сервер: `python server_api.py`
4.  Сервер будет доступен, например, по адресу `http://<your_server_ip>:5000`.

## 🌐 Документация API

Сервер предоставляет следующие HTTP-эндпоинты:

### 1. Обработка видео (`/process_video`)

*   **Метод:** `POST`
*   **Описание:** Принимает видеофайл, обрабатывает его с наложением разметки, анализа LSTM и подсчёта повторений, и возвращает обработанное видео.
*   **URL:** `http://<your_server_ip>:5000/process_video`
*   **Headers:** `Content-Type: multipart/form-data`
*   **Параметры:**
    *   `file`: (Обязательный) Загружаемый видеофайл (`MP4`, `AVI`, `MOV`, `MKV`).
*   **Пример запроса (curl):**
    ```bash
    curl -X POST -F "file=@path/to/your/video.mp4" http://127.0.0.1:5000/process_video
    ```
*   **Пример запроса (Python requests):**
    ```python
    import requests

    url = 'http://127.0.0.1:5000/process_video'
    with open('path/to/your/video.mp4', 'rb') as f:
        files = {'file': f}
        response = requests.post(url, files=files)

    if response.status_code == 200:
        with open('processed_video.mp4', 'wb') as f:
            f.write(response.content)
        print("Обработанное видео сохранено как processed_video.mp4")
    else:
        print(f"Ошибка: {response.json()}")
    ```
*   **Ответ:**
    *   **Успешно (200 OK):** Возвращает обработанный видеофайл в формате `MP4`.
    *   **Ошибка (400 Bad Request):** JSON с описанием ошибки (например, "No file part in the request", "Invalid file type").
    *   **Ошибка (500 Internal Server Error):** JSON с описанием внутренней ошибки сервера.
*   **Примечание:** После успешной обработки это видео становится доступным через эндпоинт `/last_video`.

### 2. Получение последнего обработанного видео (`/last_video`)

*   **Метод:** `GET`
*   **Описание:** Возвращает последнее видео, успешно обработанное через эндпоинт `/process_video`.
*   **URL:** `http://<your_server_ip>:5000/last_video`
*   **Пример запроса (curl):**
    ```bash
    curl -X GET http://127.0.0.1:5000/last_video
    ```
*   **Пример запроса (Python requests):**
    ```python
    import requests

    url = 'http://127.0.0.1:5000/last_video'
    response = requests.get(url)

    if response.status_code == 200:
        with open('last_processed_video.mp4', 'wb') as f:
            f.write(response.content)
        print("Последнее обработанное видео сохранено как last_processed_video.mp4")
    else:
        print(f"Ошибка: {response.json()}")
    ```
*   **Ответ:**
    *   **Успешно (200 OK):** Возвращает последний обработанный видеофайл в формате `MP4`.
    *   **Ошибка (404 Not Found):** JSON с описанием ошибки ("No last video available"), если ни одного видео ещё не было обработано или файл был потерян.

### 3. Проверка состояния сервера (`/health`)

*   **Метод:** `GET`
*   **Описание:** Проверяет, запущен ли сервер и успешно ли загружены модели.
*   **URL:** `http://<your_server_ip>:5000/health`
*   **Пример запроса (curl):**
    ```bash
    curl http://127.0.0.1:5000/health
    ```
*   **Ответ:**
    *   **Успешно (200 OK):** JSON, например:
        ```json
        {
            "status": "healthy",
            "models_loaded": true
        }
        ```
        или
        ```json
        {
            "status": "healthy",
            "models_loaded": false
        }
        ```
    *   **Ошибка (500 Internal Server Error):** Если сервер не отвечает.

## Основные функции (десктопной версии):

*   **Настройка конфигурации.** При первом запуске автоматически запускается тестирование системы:
    *   Проверка наличия GPU и CUDA
    *   Анализ характеристик CPU и RAM
    *   Тестирование камеры и определение максимального FPS
    *   Рекомендация оптимальной конфигурации
*   **Запись с камеры**
    *   Нажмите кнопку "▶ Начать запись" для начала записи
    *   Приложение будет записывать видео с камеры с наложенными точками позы
*   **Обработка видео файлов**
    *   Нажмите кнопку "🎬 Обработать видео" для выбора файла
    *   Выберите видео файл в формате MP4, AVI, MOV или MKV
    *   Приложение обработает видео и сохранит результаты
*   **Оценка симметрии выполнения любого упражнения**
    *   Пока работает плохо, рекомендуется подбирать ракурс лицом к камере,
        для корректной работы.
*   **LSTM модель для оценки качества и правильности выполнения** возвращает
    информацию об ошибках при выполнении упражнения.
*   **AI gym от ultralitics** для подсчета количества повторений и визуализации
